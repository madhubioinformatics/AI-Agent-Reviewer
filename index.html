How to use AI Agent Reviewer

  1. Add the manuscript. Paste text on the left, or upload a PDF / Word / TXT file.
  2. Set the tone. The dial runs from Kind mentor to Reviewer #2 from hell — the interface heats up as you raise it.
  3. Pick a target journal (optional). It recalibrates the bar: a "major revision" for a specialist journal can be a "reject" for a flagship.
  4. Just talk. Ask for a full review, the top fixes, a decision letter — anything. It remembers the conversation, so follow up ("now be harsher", "expand point 3").
  5. Look up the literature (optional). With PubMed / bioRxiv on, give it a PMID / DOI / title to fetch and review, or ask it to check your claims.
  6. Export. Use the PDF / Word / Copy buttons under any reply, or type "download as PDF and Word".

Grounded in the text you give it — it won't invent references. Reviews are assistive, not a substitute for real peer review.
